spidiboost.LittlePet
Автор самостоятельного мода: SpidiBoost
Minecraft Java 1.21.4 · Fabric Loader 0.16.10+ · Fabric API для 1.21.4 · Java 21
AdminTools/ATools не нужен.

Установите LittlePet-1.21.4-${version}.jar в mods отдельного профиля Fabric.
Правый Shift в мире — меню. Переназначение: Управление → Назначение клавиш → LittlePet → ClickGui.
Общий бинд с ATools: первое нажатие — ATools, повторное — LittlePet, следующее — закрыть.
Питомец: поиск по названию или ID, колесо/стрелки, Enter. Все ванильные мобы Minecraft 1.21.4 и пять цветов попугая.
Для «Кастом»: ник в «Скин» + Enter, изображение в «Лицо» + кнопка «…» или путь.
Оба варианта работают вместе. Пустой ник + Enter возвращает Стива.
Настройки сохранены в config/littlepet-spidiboost.json.

Не устанавливайте сюда LittlePet-патч для ATools.
Передавайте друзьям полный friends.zip: мод, исходники и лицензии моделей.
Источники и авторы моделей — THIRD-PARTY-NOTICES.md.
